# Boltz-2 complex-prediction inputs

This directory preserves the Boltz input YAML files currently collected for the
post-hoc structural analyses.

## Reported command settings

The predictions were run with Boltz-2 version 2.1.1. The original cluster
script invoked `boltz predict` with the following settings:

| Setting | Reported value |
|---|---:|
| Boltz-2 version | 2.1.1 |
| Potentials | enabled (`--use_potentials`) |
| MSA generation | Boltz MSA server (`--use_msa_server`) |
| Diffusion samples | 5 (`--diffusion_samples 5`) |
| Recycling steps | 5 (`--recycling_steps 5`) |
| Output format | PDB (`--output_format pdb`) |
| Output directory | one directory per input group |

Run a collected input group with an environment in which `boltz` is already on
`PATH`:

```bash
bash examples/structural_analysis/boltz2/run_boltz_predict.sh \
  examples/structural_analysis/boltz2/inputs/figure3 \
  results/boltz2/figure3
```

For the analog inputs:

```bash
bash examples/structural_analysis/boltz2/run_boltz_predict.sh \
  examples/structural_analysis/boltz2/inputs/figure4_figureS9_S10 \
  results/boltz2/figure4_figureS9_S10
```

## Figure-to-input map

| Reported analysis | Input files |
|---|---|
| Figure 3, *E. coli* PBP1A complexes | `figure3/Mianserin_pdb_ecoli.yaml`, `figure3/Ampicillin_pdb_ecoli.yaml` |

| Supplementary Figure 9 | `figure4_figureS9_S10/M-003.yaml`, `M-003_M-001.yaml`, `M-003_M-002.yaml` |
| Supplementary Figure 10 | `figure4_figureS9_S10/F-004.yaml`, `F-004_F-005.yaml`, `F-004_M-005.yaml` |
| Parent compounds retained for traceability | `figure4_figureS9_S10/M-001.yaml`, `M-003.yaml`, `F-004.yaml` |

Each YAML uses schema `version: 1`, protein chain `A`, ligand chain `B`, and an
affinity property whose binder is chain `B`. Protein sequences and ligand SMILES
are included directly in the YAML files.

## MSA generation and reuse

The original analysis reused an A3M file generated by the Boltz-2 MSA server
to reduce repeated computation. To keep the deposited inputs portable, the
YAML files do not contain a machine-specific `msa` path. The bundled runner
uses `--use_msa_server` and regenerates the corresponding MSA when the
predictions are reproduced.
